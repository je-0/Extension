# 📄 페이지 정보 추출기 - Chrome Extension

웹페이지의 구조적 정보를 쉽게 추출하고 시각화할 수 있는 Chrome 확장 프로그램입니다.

## ✨ 주요 기능

### 1. **H태그 추출**
- 페이지의 모든 `h1` ~ `h6` 태그를 수집하여 표시
- 태그 레벨별 색상 구분으로 시각적 구분
- 각 헤딩의 텍스트 내용과 순서 확인 가능

### 2. **Alt Text 추출**
- 이미지의 `alt` 속성 텍스트를 수집하여 표시
- 이미지 소스 URL 정보 제공
- 접근성 검사에 유용

### 3. **Section 정보 추출**
- 페이지의 `section` 요소 정보 수집
- 각 섹션의 ID, 클래스명, 제목 정보 제공
- 섹션 내용 미리보기 제공

### 4. **화면 오버레이 표시**
- 각 탭에서 "화면에 표시" 버튼을 통해 페이지에 직접 하이라이트 표시
- 요소 위치에 오버레이로 정보 표시
- 스크롤 시 자동으로 위치 업데이트
- 언제든지 숨기기 가능

## 🚀 설치 방법

### Chrome 웹 스토어 설치 (준비 중)
- Chrome 웹 스토어에서 검색하여 설치

### 개발자 모드로 설치
1. Chrome 브라우저에서 `chrome://extensions/` 접속
2. 우측 상단의 **"개발자 모드"** 토글 활성화
3. **"압축해제된 확장 프로그램을 로드합니다"** 버튼 클릭
4. 이 프로젝트 폴더 선택

## 📖 사용 방법

1. **확장 프로그램 활성화**
   - 설치 후 브라우저 툴바에 확장 프로그램 아이콘이 표시됩니다
   - 아이콘이 보이지 않으면 확장 프로그램 메뉴에서 고정하세요

2. **페이지 정보 확인**
   - 정보를 확인하고 싶은 웹페이지에 접속
   - 확장 프로그램 아이콘 클릭
   - 팝업에서 **H태그**, **Alt Text**, **Section** 탭을 통해 정보 확인

3. **화면에 표시 기능**
   - 각 탭의 **"화면에 표시"** 버튼 클릭
   - 페이지의 해당 요소들이 하이라이트되고 오버레이로 정보가 표시됩니다
   - **"숨기기"** 버튼으로 오버레이 제거 가능

## 📁 프로젝트 구조

```
Extension/
├── manifest.json      # 확장 프로그램 설정 파일 (Manifest V3)
├── popup.html         # 팝업 UI 구조
├── popup.js           # 팝업 로직 및 데이터 표시
├── content.js         # 페이지에서 데이터 수집 및 오버레이 관리
├── styles.css         # 팝업 스타일시트
└── README.md          # 프로젝트 문서
```

## 🔧 기술 스택

- **Manifest V3**: 최신 Chrome 확장 프로그램 API
- **Vanilla JavaScript**: 프레임워크 없이 순수 JavaScript 사용
- **Chrome Extension APIs**:
  - `chrome.tabs`: 탭 정보 조회 및 메시지 전송
  - `chrome.runtime`: 메시지 통신
  - Content Scripts: 페이지 DOM 접근

## 📋 파일별 상세 설명

### `manifest.json`
- 확장 프로그램의 메타데이터 및 권한 설정
- `activeTab` 권한으로 현재 탭에만 접근
- Content Script를 모든 URL에 주입

### `popup.html`
- 확장 프로그램 팝업의 HTML 구조
- 3개의 탭으로 구성 (H태그, Alt Text, Section)
- 각 탭별 정보 표시 영역 및 화면 표시 버튼

### `popup.js`
- 팝업의 모든 로직 처리
- 현재 탭과 통신하여 페이지 정보 수신
- 탭 전환 및 데이터 표시 관리
- 오버레이 표시/숨기기 요청

### `content.js`
- 페이지 DOM에서 정보 수집
- H태그, Alt Text, Section 데이터 추출
- 오버레이 생성 및 관리
- 스크롤/리사이즈 이벤트 처리

### `styles.css`
- 모던하고 깔끔한 UI 디자인
- 반응형 레이아웃
- 태그 레벨별 색상 구분
- 부드러운 애니메이션 효과

## 🎨 주요 특징

- **사용자 친화적 UI**: 직관적이고 깔끔한 인터페이스
- **실시간 정보**: 페이지 로드 시 즉시 정보 수집
- **시각적 하이라이트**: 페이지에서 직접 요소 위치 확인
- **성능 최적화**: 효율적인 DOM 쿼리 및 이벤트 처리
- **접근성 고려**: Alt Text 추출로 접근성 검사 지원

## 🔍 사용 사례

- **웹 개발자**: 페이지 구조 분석 및 SEO 최적화
- **접근성 검사**: Alt Text 누락 확인
- **콘텐츠 분석**: 헤딩 구조 및 섹션 구성 파악
- **QA 테스터**: 페이지 구조 검증

## ⚠️ 주의사항

- 일부 동적 콘텐츠는 페이지 로드 후 새로고침이 필요할 수 있습니다
- `chrome://` 및 `chrome-extension://` 페이지에서는 작동하지 않습니다
- 오버레이 표시 중에는 페이지 스크롤이 가능하며, 오버레이 위치가 자동으로 업데이트됩니다
